# Content sources

The app bundles one read-only SQLite content database, `assets/content/content.db`. It is generated by the content build from third-party sources, which are kept out of git in `content/sources/`.

```sh
npm run content:fetch   # downloads the public sources into content/sources/
npm run content:build   # writes assets/content/content.db
```

Bump `CONTENT_VERSION` in `src/content/version.ts` whenever the generated database changes, so installed apps pick up the new copy.

## Sources

| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `quran-uthmani.txt`             | [Tanzil](https://tanzil.net) Uthmani text, fetched by `content:fetch`                                                                           | CC BY 3.0 with a no-changes clause: use verbatim, credit Tanzil with a link to tanzil.net, keep the copyright notice (stored in the database's `meta` table) |
| `quran-morphology.txt`          | [mustafa0x/quran-morphology](https://github.com/mustafa0x/quran-morphology), a corrected [Quranic Arabic Corpus](https://corpus.quran.com) v0.4 | GNU GPL; credit and link corpus.quran.com. Permission for app use to be confirmed with the corpus maintainer before release                                  |
| `qul-english-word-by-word.json` | [QUL](https://qul.tarteel.ai) "English Word by Word Translation" (Tarteel). **Manual download, needs a QUL account**                            | No license stated. **Written permission from Tarteel required before release**                                                                               |

To get the QUL file: sign in at [qul.tarteel.ai](https://qul.tarteel.ai), open the [English Word by Word Translation](https://qul.tarteel.ai/resources/translation/92) resource, choose **Download json**, and save it as `content/sources/qul-english-word-by-word.json`.

## Fonts

Quran text is rendered with **Amiri Quran** (`assets/fonts/`, SIL Open Font License, see `AmiriQuran-OFL.txt`) until written permission for the KFGQPC Uthmanic Hafs font is obtained. The font is configured only in `src/theme/quranFont.ts`.
